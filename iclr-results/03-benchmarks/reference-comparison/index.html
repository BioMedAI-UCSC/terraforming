Mars: model, Ames, MCD and ARCO

Physical baseline diagnostic. No calibrated or equilibrium improvement is implied.

  • This compares the existing physical baseline, not the pending 0.25-sol gradient-calibration result.
  • Model fields average sparse instantaneous seasonal checkpoints; Ames uses five-sol means; ARCO uses daily means; MCD here averages only local times 0, 6, 12 and 18 h.
  • Ames and MCD are model references; ARCO-MACDA is a reanalysis, not direct observational truth.
  • Wind compares lowest atmospheric levels with MCD at 10 m; heights are not identical.
  • MCD cached seasons are near the labeled target (up to about 1.2 degrees apart); original attributes and hashes are recorded. Legacy cached dust-query provenance is not independently verified.
  • MOLA is common geographic context, not evidence that all reference models use the same terrain.
  • Model parameter values below are the declared baseline configuration from the progress report; they are not independently recoverable from every seasonal NetCDF.
  • All reference maps are linearly regridded onto the model grid. Missing fields are unavailable, never zero-filled.
  • MCD CO2 frost is a monthly mean statistic, which differs from the model and other reference sampling.
